# Dataset Information

This project uses the **DataCo Smart Supply Chain Dataset** covering transactions from **2015–2018**, modeled into a star schema (`Fact_Orders`, `Dim_Date`, `Dim_Geography`, `Dim_Customer`, `Dim_Product`) inside the Power BI report (`Pbix/`).

Raw dataset files are omitted from `Data/` due to repository file size limits. The raw dataset is publicly available on platforms such as **Kaggle** (DataCo Supply Chain listings).
